# CTRLSuite — test builds

This repository holds **test builds** of [CTRLSuite](https://github.com/ctrlsuite-app/ctrlsuite-downloads): versions made to
be tried before they become a stable release. They are **not releases** and they are not meant for everyone.

- Only copies installed from a test build look here for updates. Stable copies never do.
- Versions look like `1.0.5-test.202609191253`: the next patch after the stable version, dated to the minute (UTC).
- Only the newest few test builds are kept.

Looking for the app? Stable versions, with the installer and the zip, are in
**[ctrlsuite-downloads](https://github.com/ctrlsuite-app/ctrlsuite-downloads/releases/latest)**.
